# Structural Patterns

Describe how to assemble objects and classes into larger structures while keeping them flexible and efficient.

| Pattern | Intent |
|---|---|
| [Adapter](adapter/) | Convert an interface into another one clients expect |
| [Bridge](bridge/) | Decouple abstraction from implementation so both can vary independently |
| [Composite](composite/) | Compose objects into trees; treat leaves and composites uniformly |
| [Decorator](decorator/) | Attach additional behaviour to objects at runtime via wrapping |
| [Facade](facade/) | Provide a simplified interface to a complex subsystem |
| [Flyweight](flyweight/) | Share common state among many fine-grained objects to save memory |
| [Proxy](proxy/) | Control access to an object via a surrogate with the same interface |
